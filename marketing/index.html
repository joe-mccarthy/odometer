01 / TRACK

More than fuel.

Record servicing, insurance, tax, tyres, repairs and the other costs that add up. Keep multiple vehicles in one place.

＋
02 / UNDERSTAND

Make the miles count.

See running and ownership cost per mile, UK MPG, category breakdowns and monthly or annual summaries.

↗
03 / OWN

Keep your keys.

Your records live in a local SQLite database. Use the CLI, terminal dashboard or local browser. Export JSON/CSV and back up SQLite through the CLI. Docker supports CLI/TUI use.

YOUR NEXT MILE STARTS HERE

Pop the bonnet.
Get started.

Made for people who are comfortable in a terminal. Bring Python 3.12–3.x, Git and Poetry 2.4.x.

Early-stage software · GitHub-only testing release.
Odometer is not published to PyPI yet.

Read the setup guide ↗
GET UP AND RUNNING
git clone https://github.com/joe-mccarthy/odometer.git
cd odometer
poetry install
poetry run odometer init
poetry run odometer tui

Then add your vehicle and start logging. See basic usage →
